家庭學習刷題站

使用方式：
1. 解壓縮 ZIP。
2. 直接以瀏覽器開啟 index.html 即可使用。
3. 若要公開上線，可將 index.html、style.css、app.js、batch.js、batch.css、README.txt、題庫格式說明.md 上傳到 GitHub Repository，並在 Settings > Pages 選擇部署分支與根目錄。

目前版本：
- 國小五年級：國語、社會（南一）；英文、數學、自然（康軒）
- 國小六年級：國語、英文、社會（康軒）；數學（翰林）；自然（南一）
- 國中一年級至三年級：國文、英文、數學、自然、歷史、地理、公民（版本不限）
- ZOEY / PEGGY 分開紀錄（舊版學生 A、學生 B 的紀錄會自動搬移至新名稱）
- 題目作答、即時批改、解析、成績統計、錯題本、錯題複習
- 一般測驗只從不同題目 ID 中隨機抽取 10 題，不會重複；題庫不足 10 題時會提示，不會複製題目湊數
- 本次匯入五年級社會 28 題：臺北市民權國小 114 學年度上學期期中評量，答案依《題目.pdf》題目卷括號內標示整理；解析為輔助說明
- 本機瀏覽器 localStorage 儲存，不需要伺服器
- 新增「匯入題庫測驗」（batch.js、batch.css）：家長匯入 AI 做的題庫 JSON；引導題／獨立作答；答錯先提示、再想一次；逐題計時與離開紀錄；成績匯出 JSON 給 AI 分析；完整備份與還原。格式見「題庫格式說明.md」
- 「重設本機資料」只清除每日 10 題的紀錄，不會清除匯入題庫的作答紀錄

重要說明：
本版仍未達成每科 100 題。此次上傳的《題目.pdf》含多份不同學校、年級、科目及學期的試卷；《答案.pdf》部分答案標示為 AI 生成。為避免跨試卷配錯答案，本次只先匯入題目卷中答案標示清楚且可確認的五年級社會 28 道選擇題。其餘試卷尚未匯入，需逐份核對題目與答案後再加入。

隱私與資料：
紀錄只存在使用者目前瀏覽器/裝置。清除瀏覽器網站資料或更換裝置可能導致紀錄消失；目前尚未提供跨裝置同步或家長登入管理功能。

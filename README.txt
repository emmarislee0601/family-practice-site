家庭學習刷題站

使用方式：
1. 解壓縮 ZIP。
2. 直接以瀏覽器開啟 index.html 即可使用。
3. 若要公開上線，可將 index.html、style.css、app.js、README.txt 上傳到 GitHub Repository，並在 Settings > Pages 選擇部署分支與根目錄。

目前版本：
- 國小五年級：國語、社會（南一）；英文、數學、自然（康軒）
- 國小六年級：國語、英文、社會（康軒）；數學（翰林）；自然（南一）
- 國中一年級至三年級：國文、英文、數學、自然、歷史、地理、公民（版本不限）
- ZOEY / PEGGY 分開紀錄（舊版學生 A、學生 B 的紀錄會自動搬移至新名稱）
- 題目作答、即時批改、解析、成績統計、錯題本、錯題複習
- 本機瀏覽器 localStorage 儲存，不需要伺服器

重要說明：
本版內含各年級各科原創示範題，並非各出版社課本原題，也不代表完整學期題庫。若要擴充為正式大量題庫，可持續在 app.js 的 bank 資料中加入題目；建議依學期、單元、難度與題型分類。

隱私與資料：
紀錄只存在使用者目前瀏覽器/裝置。清除瀏覽器網站資料或更換裝置可能導致紀錄消失；目前尚未提供跨裝置同步或家長登入管理功能。
